# 08 — Analysis of Variance (ANOVA)

ANOVA ใช้ตอบคำถามว่า **ค่าเฉลี่ยของตั้งแต่ 3 กลุ่มขึ้นไปแตกต่างกันหรือไม่** เช่น วิธีล้างมือ 4 วิธีให้จำนวนแบคทีเรียเฉลี่ยต่างกันหรือไม่ หรือระบบบริการ 3 ระบบได้คะแนนความง่ายในการใช้งานต่างกันหรือไม่

หัวใจของบทนี้ไม่ใช่การจำตาราง ANOVA แต่คือการแยกให้ออกว่าโจทย์มี **ตัวแปรผลลัพธ์เชิงปริมาณกี่ตัว** และมี **ปัจจัยที่ใช้แบ่งกลุ่มกี่ปัจจัย**

- ผลลัพธ์หนึ่งตัว + ปัจจัยหนึ่งตัว → One-way ANOVA
- ผลลัพธ์หนึ่งตัว + ปัจจัยสองตัว → Two-way ANOVA
- ถ้าสองปัจจัยอาจส่งผลร่วมกัน ต้องพิจารณา interaction

## 1. ทำไมไม่ใช้ t-test เปรียบเทียบทีละคู่

สมมติว่าต้องเปรียบเทียบค่าเฉลี่ยของ 4 กลุ่ม จะมีคู่เปรียบเทียบทั้งหมด

$$
\frac{4(4-1)}{2} = 6 \text{ คู่}
$$

ถ้าใช้ t-test แยก 6 ครั้ง แต่ละครั้งมีโอกาสผิดพลาดแบบที่ 1 เท่ากับ 0.05 โอกาสพบผลต่างโดยบังเอิญในอย่างน้อยหนึ่งคู่จะสูงกว่า 0.05 การทดสอบ ANOVA จึงเริ่มด้วยคำถามรวมเพียงครั้งเดียวว่า

> มีหลักฐานหรือไม่ว่าอย่างน้อยหนึ่งกลุ่มมีค่าเฉลี่ยแตกต่างจากกลุ่มอื่น

สมมติฐานของ One-way ANOVA เมื่อมี $k$ กลุ่มคือ

$$
H_0: \mu_1 = \mu_2 = \cdots = \mu_k
$$

$$
H_1: \text{มีค่าเฉลี่ยอย่างน้อยหนึ่งคู่ที่แตกต่างกัน}
$$

ข้อสำคัญคือ เมื่อปฏิเสธ $H_0$ เรารู้เพียงว่า **มีความแตกต่างบางแห่ง** แต่ยังไม่รู้ว่าเป็นคู่ใด ต้องใช้การเปรียบเทียบภายหลัง เช่น Tukey HSD

## 2. ภาพคิดของ ANOVA: ความต่างระหว่างกลุ่มเทียบกับความผันผวนในกลุ่ม

ลองนึกถึงคะแนนสอบของนักเรียน 3 ห้อง

- ถ้าค่าเฉลี่ยแต่ละห้องห่างกันมาก แต่คะแนนของนักเรียนในห้องเดียวกันเกาะกลุ่มกันแน่น หลักฐานว่าห้องต่างกันจะชัด
- ถ้าค่าเฉลี่ยแต่ละห้องห่างกันเล็กน้อย แต่คะแนนภายในแต่ละห้องกระจายมาก ความต่างที่เห็นอาจเกิดจากความผันผวนตามธรรมชาติ

ANOVA จึงสร้างอัตราส่วน

$$
F = \frac{MS_{\text{between}}}{MS_{\text{within}}}
$$

- $MS_{\text{between}}$ วัดความแตกต่างระหว่างค่าเฉลี่ยกลุ่ม
- $MS_{\text{within}}$ วัดความผันผวนของข้อมูลภายในกลุ่มเดียวกัน

ถ้า $H_0$ เป็นจริง ค่า $F$ มักใกล้ 1 เพราะความผันผวนสองส่วนมีขนาดใกล้กัน ถ้า $F$ ใหญ่ แสดงว่าความต่างระหว่างกลุ่มเด่นกว่าความผันผวนภายในกลุ่ม

ความผันแปรรวมแยกได้เป็น

$$
SS_{\text{total}} = SS_{\text{between}} + SS_{\text{within}}
$$

ตาราง One-way ANOVA มีโครงสร้างดังนี้

| แหล่งความผันแปร | Sum of Squares | df | Mean Square | สถิติทดสอบ |
|---|---:|---:|---:|---:|
| ระหว่างกลุ่ม | $SS_{\text{between}}$ | $k-1$ | $SS_{\text{between}}/(k-1)$ | $F=MS_{\text{between}}/MS_{\text{within}}$ |
| ภายในกลุ่ม | $SS_{\text{within}}$ | $n-k$ | $SS_{\text{within}}/(n-k)$ | |
| รวม | $SS_{\text{total}}$ | $n-1$ | | |

ในห้องสอบไม่จำเป็นต้องคำนวณทุกช่องด้วยมือถ้าใช้ R ได้ แต่ควรรู้ว่าเลขแต่ละช่องตอบคำถามอะไร

## 3. ก่อนใช้ One-way ANOVA ต้องเห็นโครงสร้างนี้

ตัวอย่างคำถาม: “เงินเดือนเริ่มต้นเฉลี่ยของผู้จบจากมหาวิทยาลัย 3 แห่งแตกต่างกันหรือไม่”

- ตัวแปรผลลัพธ์: เงินเดือนเริ่มต้น เป็นข้อมูลเชิงปริมาณ
- ปัจจัย: มหาวิทยาลัย เป็นข้อมูลแบ่งกลุ่ม
- จำนวนระดับของปัจจัย: 3 ระดับ
- หน่วยตัวอย่างแต่ละคนอยู่เพียงหนึ่งกลุ่ม

จึงใช้ One-way ANOVA

### ข้อตกลงเบื้องต้น

1. หน่วยตัวอย่างเป็นอิสระต่อกัน ความเป็นอิสระมาจากวิธีเก็บข้อมูล ไม่สามารถพิสูจน์ด้วยกราฟได้
2. residuals ภายในแต่ละกลุ่มมีการแจกแจงใกล้ปกติ
3. ความแปรปรวนของแต่ละกลุ่มใกล้เคียงกัน
4. ไม่มี outlier รุนแรงที่ครอบงำผลวิเคราะห์

ตรวจข้อมูลเบื้องต้นใน R ได้ดังนี้

```r
%%R
boxplot(salary ~ university, data = salary_data)

salary_model <- aov(salary ~ university, data = salary_data)
par(mfrow = c(1, 2))
plot(salary_model, which = 1)
plot(salary_model, which = 2)
```

- Residuals vs Fitted ใช้ดูรูปแบบผิดปกติและการกระจายที่กว้างขึ้นหรือแคบลง
- Normal Q-Q ใช้ดูว่า residuals เบี่ยงจากเส้นตรงมากหรือไม่
- Boxplot ใช้ดูการกระจายและ outlier ของแต่ละกลุ่ม

ถ้าความแปรปรวนไม่เท่ากัน แต่กลุ่มยังเป็นอิสระ ใช้ Welch ANOVA ได้

```r
%%R
oneway.test(salary ~ university, data = salary_data, var.equal = FALSE)
```

## 4. One-way ANOVA: ตัวอย่างเงินเดือนเริ่มต้น

ข้อมูลจากสไลด์มีหน่วยเป็นพันบาท

- University 1: 17.4, 16.5, 17.2, 16.9
- University 2: 17.5, 16.8, 17.4, 17.6, 18.2
- University 3: 15.6, 13.5, 16.3, 15.2

### 4.1 รันใน Google Colab

เซลล์แรกของ notebook:

```python
%load_ext rpy2.ipython
```

ตั้งค่าการแสดงตัวเลข:

```r
%%R
options(scipen = 999, digits = 4)
```

สร้างข้อมูลและดูค่าเฉลี่ย:

```r
%%R
salary_data <- data.frame(
  university = factor(c(
    rep("University 1", 4),
    rep("University 2", 5),
    rep("University 3", 4)
  )),
  salary = c(
    17.4, 16.5, 17.2, 16.9,
    17.5, 16.8, 17.4, 17.6, 18.2,
    15.6, 13.5, 16.3, 15.2
  )
)

print(aggregate(salary ~ university, data = salary_data, mean))
```

ผลเฉลี่ยคือ 17.00, 17.50 และ 15.15 ตามลำดับ แต่การเห็นค่าเฉลี่ยต่างกันในตัวอย่างยังไม่พอ ต้องทดสอบว่าแตกต่างเกินกว่าความผันผวนตามธรรมชาติหรือไม่

### 4.2 รัน ANOVA

```r
%%R
salary_model <- aov(salary ~ university, data = salary_data)
print(summary(salary_model))
```

ผลจากสไลด์คือ

| Source | SS | df | MS | F | p-value |
|---|---:|---:|---:|---:|---:|
| University | 13.093 | 2 | 6.547 | 11.465 | 0.003 |
| Residuals | 5.710 | 10 | 0.571 | | |
| Total | 18.803 | 12 | | | |

เพราะ $p=0.003<0.05$ จึงปฏิเสธ $H_0$ และสรุปว่ามีมหาวิทยาลัยอย่างน้อยหนึ่งคู่ที่มีเงินเดือนเริ่มต้นเฉลี่ยแตกต่างกัน

### 4.3 หาให้ได้ว่าคู่ใดต่างกัน

```r
%%R
print(TukeyHSD(salary_model))
```

ผล Tukey HSD จากสไลด์:

| คู่เปรียบเทียบ | ผลต่างค่าเฉลี่ย | p-value | สรุปที่ระดับ 0.05 |
|---|---:|---:|---|
| University 1 − University 2 | -0.50 | 0.601 | ไม่พบความแตกต่าง |
| University 1 − University 3 | 1.85 | 0.015 | แตกต่าง |
| University 2 − University 3 | 2.35 | 0.002 | แตกต่าง |

ดังนั้น University 1 และ University 2 ไม่ต่างกันอย่างมีนัยสำคัญ แต่ทั้งสองแห่งมีค่าเฉลี่ยสูงกว่า University 3

### 4.4 แบบเขียนตอบข้อสอบ

> ใช้ One-way ANOVA เพื่อเปรียบเทียบเงินเดือนเริ่มต้นเฉลี่ยของผู้จบจากมหาวิทยาลัย 3 แห่ง ที่ระดับนัยสำคัญ 0.05 ผลการทดสอบได้ $F(2,10)=11.465$ และ $p=0.003$ จึงปฏิเสธ $H_0$ สรุปว่ามีเงินเดือนเริ่มต้นเฉลี่ยอย่างน้อยหนึ่งคู่แตกต่างกัน ผล Tukey HSD พบว่า University 1 และ University 2 ไม่แตกต่างกัน แต่ทั้งสองแห่งมีค่าเฉลี่ยสูงกว่า University 3 อย่างมีนัยสำคัญทางสถิติ

## 5. ANOVA บอกว่าต่าง แต่ Post-hoc บอกว่าคู่ใดต่าง

ลำดับการตอบที่ปลอดภัยคือ

1. อ่าน p-value ของ ANOVA ก่อน
2. ถ้าไม่ปฏิเสธ $H_0$ ให้หยุด ไม่ควรเลือกดูเฉพาะคู่ที่ดูเหมือนต่าง
3. ถ้าปฏิเสธ $H_0$ จึงอ่าน Tukey HSD
4. รายงานทั้งทิศทางของผลต่างและ p-value หรือช่วงความเชื่อมั่น

Tukey HSD เหมาะกับการเปรียบเทียบทุกคู่และควบคุมความน่าจะเป็นของความผิดพลาดรวมในชุดการเปรียบเทียบ ส่วน LSD และ Duncan มีความเข้มงวดน้อยกว่า จึงอาจพบคู่ที่มีนัยสำคัญได้ง่ายกว่า ในงานทั่วไปให้เลือก Tukey หากโจทย์ไม่ได้กำหนดวิธีอื่น

## 6. แบบฝึกหัดจากสไลด์: วิธีล้างมือกับจำนวนแบคทีเรีย

โจทย์ต้องการเปรียบเทียบจำนวนแบคทีเรียหลังใช้วิธีล้างมือ 4 วิธี ข้อมูลผลลัพธ์เป็นจำนวนแบคทีเรีย และปัจจัยคือวิธีล้างมือ จึงใช้ One-way ANOVA

### 6.1 รัน R ก่อน

```r
%%R
bacteria_data <- data.frame(
  method = factor(rep(c(
    "Alcohol spray", "Antibacterial soap", "Soap", "Water"
  ), each = 8)),
  bacteria = c(
    51, 5, 19, 18, 58, 50, 82, 17,
    70, 164, 88, 111, 73, 119, 20, 95,
    84, 51, 110, 67, 119, 108, 207, 102,
    74, 135, 102, 124, 105, 130, 170, 87
  )
)

bacteria_model <- aov(bacteria ~ method, data = bacteria_data)
print(aggregate(bacteria ~ method, data = bacteria_data, mean))
print(summary(bacteria_model))
print(TukeyHSD(bacteria_model))
```

ผลสำคัญที่ควรเห็น:

- ค่าเฉลี่ยเท่ากับ 37.50, 92.50, 106.00 และ 115.875 ตามลำดับ
- ANOVA ได้ประมาณ $F(3,28)=7.001$ และ $p=0.0012$
- Tukey HSD พบว่า Alcohol spray ต่างจากอีก 3 วิธี
- ยังไม่พบความแตกต่างระหว่าง Antibacterial soap, Soap และ Water

### 6.2 แบบเขียนตอบข้อสอบ

> ใช้ One-way ANOVA เพื่อเปรียบเทียบจำนวนแบคทีเรียเฉลี่ยหลังการล้างมือ 4 วิธี ผลการทดสอบได้ $F(3,28)=7.001$ และ $p=0.0012$ จึงปฏิเสธ $H_0$ ที่ระดับ 0.05 สรุปว่ามีค่าเฉลี่ยอย่างน้อยหนึ่งคู่แตกต่างกัน ผล Tukey HSD พบว่า Alcohol spray ให้จำนวนแบคทีเรียเฉลี่ยต่ำกว่าวิธีอื่นทั้งสามอย่างมีนัยสำคัญ แต่ยังไม่พบความแตกต่างระหว่างอีกสามวิธี

คำว่า “ต่ำกว่า” ในที่นี้อธิบายข้อมูลเชิงสถิติเท่านั้น การสรุปว่าเป็นวิธีที่ดีที่สุดยังต้องพิจารณาการออกแบบการทดลอง ความปลอดภัย และบริบทการใช้งาน

## 7. Two-way ANOVA: เมื่อมีปัจจัยสองตัว

Two-way ANOVA ใช้เมื่อมีผลลัพธ์เชิงปริมาณหนึ่งตัวและมีปัจจัยแบ่งกลุ่มสองตัว เช่น

- ผลลัพธ์: จำนวนวันขาดงาน
- ปัจจัย A: ประเภทคลังสินค้า
- ปัจจัย B: ช่วงหลังการอบรม

Two-way ANOVA ตอบได้ 3 คำถาม

1. ปัจจัย A มีผลต่อค่าเฉลี่ยหรือไม่
2. ปัจจัย B มีผลต่อค่าเฉลี่ยหรือไม่
3. ผลของ A เปลี่ยนไปตามระดับของ B หรือไม่ คำถามนี้เรียกว่า interaction

โมเดลที่มี interaction เขียนได้เป็น

$$
Y_{ijk} = \mu + \alpha_i + \beta_j + (\alpha\beta)_{ij} + \varepsilon_{ijk}
$$

ใน R เครื่องหมาย `*` หมายถึง main effects ของทั้งสองปัจจัยและ interaction

```r
two_way_model <- aov(outcome ~ factor_a * factor_b, data = my_data)
```

ซึ่งเท่ากับ

```r
aov(outcome ~ factor_a + factor_b + factor_a:factor_b, data = my_data)
```

## 8. Interaction คือสิ่งที่ต้องอ่านก่อน

สมมติว่าหลังอบรม จำนวนวันขาดงานลดลงในคลังทั่วไป แต่กลับเพิ่มขึ้นในคลังแช่เย็น ผลของการอบรมจึงไม่เหมือนกันในทุกประเภทคลัง นี่คือ interaction

กราฟ interaction ช่วยให้เห็นภาพ:

- เส้นเกือบขนาน → interaction มักมีขนาดเล็ก
- เส้นไม่ขนานหรือไขว้กัน → อาจมี interaction
- ต้องตัดสินด้วย p-value ไม่ใช่กราฟเพียงอย่างเดียว

```r
%%R
interaction.plot(
  x.factor = training,
  trace.factor = warehouse,
  response = absent_days,
  xlab = "Training period",
  ylab = "Mean absent days"
)
```

ลำดับอ่านผล Two-way ANOVA:

1. อ่าน interaction ก่อน
2. ถ้า interaction มีนัยสำคัญ ให้แยกอธิบายผลของปัจจัยหนึ่งในแต่ละระดับของอีกปัจจัย หรือวิเคราะห์ simple effects
3. ถ้า interaction ไม่มีนัยสำคัญ จึงตีความ main effects ได้ตรงไปตรงมามากขึ้น

### ตัวอย่างจากสไลด์: วันขาดงานหลังอบรม

ผลวิเคราะห์ในสไลด์ได้

| Effect | df | F | p-value |
|---|---:|---:|---:|
| Training period | 2 | 4.460 | 0.023 |
| Department | 3 | 3.157 | 0.043 |
| Training × Department | 6 | 8.950 | < 0.001 |

แม้ main effects ทั้งสองมีนัยสำคัญ แต่ interaction ก็มีนัยสำคัญและกราฟมีเส้นไขว้กัน จึงไม่ควรสรุปสั้น ๆ ว่า “การอบรมลดวันขาดงานทุกแผนก” เพราะทิศทางและขนาดของผลการอบรมแตกต่างกันตามประเภทคลังสินค้า

### แบบเขียนตอบข้อสอบ

> ผล Two-way ANOVA พบ interaction ระหว่างช่วงการอบรมกับประเภทคลังสินค้าอย่างมีนัยสำคัญ $F(6,24)=8.950$, $p<0.001$ แสดงว่าผลของการอบรมต่อจำนวนวันขาดงานไม่เหมือนกันในทุกประเภทคลังสินค้า ดังนั้นควรเปรียบเทียบช่วงการอบรมแยกภายในแต่ละประเภทคลัง ก่อนสรุปผลของการอบรม

## 9. Two-way ANOVA แบบไม่มีข้อมูลซ้ำ กับแบบมีข้อมูลซ้ำ

คำว่า “ข้อมูลซ้ำ” ในที่นี้หมายถึงมี observations มากกว่าหนึ่งค่าต่อการจับคู่ระดับของปัจจัย A และ B

### 9.1 ไม่มีข้อมูลซ้ำในแต่ละช่อง

ตัวอย่างเช่น ระบบบริการ 3 ระบบ × กลุ่มอายุ 8 กลุ่ม และมีคะแนนเพียงหนึ่งค่าต่อระบบ–กลุ่มอายุ โมเดลสามารถแยกความผันแปรของสองปัจจัยได้ แต่ไม่สามารถแยก interaction ออกจาก error ได้อย่างอิสระ

```r
%%R
model_no_replication <- aov(score ~ system + age_group, data = usability_data)
print(summary(model_no_replication))
```

ในตัวอย่างสไลด์ ระบบมีผลต่อคะแนน User-friendliness ($p=0.018$) แต่กลุ่มอายุไม่มีผลอย่างมีนัยสำคัญ ($p=0.238$) อย่างไรก็ตาม เพราะมีหนึ่ง observation ต่อช่อง จึงไม่มีการทดสอบ interaction แยกต่างหาก

### 9.2 มีข้อมูลซ้ำในแต่ละช่อง

ถ้ามีผู้ใช้หลายคนในทุกคู่ของระบบและกลุ่มอายุ จะประมาณ interaction และ residual error แยกกันได้

```r
%%R
model_with_replication <- aov(
  score ~ system * age_group,
  data = usability_data
)
print(summary(model_with_replication))
```

ดังนั้น ก่อนเขียนโมเดล Two-way ต้องถามว่า **แต่ละ combination ของสองปัจจัยมีข้อมูลกี่ค่า**

## 10. ตัวอย่าง R แบบรันได้: Two-way ANOVA พร้อม interaction

ตัวอย่างจำลองนี้วัดคะแนนหลังเรียนจากวิธีสอน 2 แบบในนักศึกษาระดับพื้นฐาน 3 ระดับ แต่ละช่องมี 4 คน และตั้งชื่อตัวแปรไม่ซ้ำกับตัวอย่างก่อนหน้า

```r
%%R
learning_data <- data.frame(
  teaching = factor(rep(c("Lecture", "Workshop"), each = 4, times = 3)),
  background = factor(rep(c("Low", "Medium", "High"), each = 8)),
  student = rep(1:4, times = 6)
)

learning_data$score <- c(
  55, 57, 54, 56,
  68, 70, 67, 69,
  63, 65, 62, 64,
  74, 76, 73, 75,
  72, 74, 71, 73,
  80, 82, 79, 81
)

learning_model <- aov(score ~ teaching * background, data = learning_data)
print(summary(learning_model))

interaction.plot(
  learning_data$background,
  learning_data$teaching,
  learning_data$score,
  xlab = "Background",
  ylab = "Mean score"
)
```

เวลาตอบ ให้ดูแถว `teaching:background` ก่อนเสมอ

- ถ้า p-value ของ interaction ต่ำกว่า 0.05: ผลของวิธีสอนขึ้นอยู่กับพื้นฐานของผู้เรียน
- ถ้า p-value ของ interaction ตั้งแต่ 0.05 ขึ้นไป: ยังไม่มีหลักฐานว่า effect ของวิธีสอนเปลี่ยนตามพื้นฐาน แล้วจึงอ่าน main effects

## 11. เลือกวิธีจากรูปโจทย์

| โครงสร้างโจทย์ | วิธีหลัก | R สั้น ๆ |
|---|---|---|
| ค่าเฉลี่ย 2 กลุ่มอิสระ | Independent t-test | `t.test(y ~ group, data = d)` |
| ค่าเฉลี่ยตั้งแต่ 3 กลุ่ม ปัจจัยเดียว | One-way ANOVA | `aov(y ~ group, data = d)` |
| ปัจจัยเดียว แต่ความแปรปรวนไม่เท่ากัน | Welch ANOVA | `oneway.test(y ~ group, data = d)` |
| ผลลัพธ์หนึ่งตัว ปัจจัยสองตัว ไม่มีข้อมูลซ้ำต่อช่อง | Two-way without replication | `aov(y ~ a + b, data = d)` |
| ผลลัพธ์หนึ่งตัว ปัจจัยสองตัว มีข้อมูลซ้ำต่อช่อง | Two-way with interaction | `aov(y ~ a * b, data = d)` |
| ANOVA มีนัยสำคัญและต้องการรู้ว่าคู่ใดต่าง | Tukey HSD | `TukeyHSD(model)` |

ถ้ากลุ่มมีเพียง 2 กลุ่ม One-way ANOVA และ independent t-test จะให้ข้อสรุปเดียวกัน โดย $F=t^2$ แต่ t-test สื่อสารทิศทางของผลต่างสองกลุ่มได้ตรงกว่า

## 12. อ่าน output ของ R ให้เป็น

เมื่อรัน `summary(aov(...))` ให้ดูคอลัมน์เหล่านี้

- `Df`: degrees of freedom
- `Sum Sq`: ปริมาณความผันแปรที่แหล่งนั้นอธิบาย
- `Mean Sq`: Sum Sq หารด้วย df
- `F value`: อัตราส่วน signal ต่อ noise
- `Pr(>F)`: p-value

ตัวอย่างบรรทัด

```text
             Df Sum Sq Mean Sq F value Pr(>F)
method        3  27012    9004   7.001 0.0012
Residuals    28  36012    1286
```

อ่านว่า ปัจจัย `method` มี 4 ระดับ จึงมี df เท่ากับ 3 และผลทดสอบได้ $F(3,28)=7.001$, $p=0.0012$

ใน `TukeyHSD()` ให้ดู

- `diff`: ค่าเฉลี่ยของกลุ่มแรก ลบ ค่าเฉลี่ยของกลุ่มหลัง
- `lwr`, `upr`: ช่วงความเชื่อมั่นของผลต่าง
- `p adj`: p-value ที่ปรับสำหรับการเปรียบเทียบหลายคู่แล้ว

ถ้าช่วง `lwr` ถึง `upr` ไม่ครอบคลุม 0 คู่ดังกล่าวแตกต่างกันอย่างมีนัยสำคัญที่ระดับความเชื่อมั่นที่กำหนด

## 13. แม่แบบเขียนตอบ

### One-way ANOVA

> ใช้ One-way ANOVA เพื่อเปรียบเทียบค่าเฉลี่ย [ตัวแปรผลลัพธ์] ระหว่าง [จำนวน] กลุ่ม ผลการทดสอบได้ $F([df_1],[df_2])=[F]$ และ $p=[p]$ จึง [ปฏิเสธ/ไม่ปฏิเสธ] $H_0$ ที่ระดับ 0.05 สรุปว่า [มี/ยังไม่มีหลักฐานว่ามี] ค่าเฉลี่ยอย่างน้อยหนึ่งคู่แตกต่างกัน [ถ้ามีนัยสำคัญ: ผล Tukey HSD พบว่า ...]

### Two-way ANOVA เมื่อ interaction ไม่มีนัยสำคัญ

> ไม่พบ interaction ระหว่าง [ปัจจัย A] กับ [ปัจจัย B], $F([df_1],[df_2])=[F]$, $p=[p]$ จึงยังไม่มีหลักฐานว่าผลของ [A] เปลี่ยนไปตาม [B] เมื่อพิจารณา main effects พบว่า [รายงานผล A และ B แยกกัน]

### Two-way ANOVA เมื่อ interaction มีนัยสำคัญ

> พบ interaction ระหว่าง [ปัจจัย A] กับ [ปัจจัย B], $F([df_1],[df_2])=[F]$, $p=[p]$ แสดงว่าผลของ [A] ต่อ [ผลลัพธ์] ขึ้นอยู่กับระดับของ [B] จึงควรเปรียบเทียบผลของ [A] แยกภายในแต่ละระดับของ [B] ก่อนสรุป main effects

คำว่า “ยอมรับ $H_0$” ควรหลีกเลี่ยง ให้ใช้ “ไม่ปฏิเสธ $H_0$” หรือ “ยังไม่มีหลักฐานเพียงพอ” เพราะ p-value สูงไม่ได้พิสูจน์ว่าค่าเฉลี่ยเท่ากันทุกประการ
