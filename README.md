## แนวทางการจัดเก็บ

เนื้อหาแต่ละสัปดาห์จัดเก็บภายใต้โฟลเดอร์ของรายวิชา:

```text
course/
└── week_01/
    ├── summary.md
    ├── exercises/
    └── images/
```

- `summary.md` — สรุปเนื้อหาที่เรียบเรียงแล้ว
- `exercises/` — แบบฝึกหัด Notebook SQL หรือไฟล์โค้ด
- `images/` — ภาพประกอบที่ใช้ในสรุป
- เอกสารต้นฉบับของอาจารย์ให้เก็บในพื้นที่ส่วนตัว เช่น OneDrive หรือ Google Drive

## หลักการตั้งชื่อ

- ชื่อ repository และโฟลเดอร์ใช้ตัวพิมพ์เล็กและคั่นคำด้วย `-`
- ชื่อไฟล์และตัวแปรในงานข้อมูลสามารถใช้ `lower_case_with_underscore`
- สัปดาห์ใช้รูปแบบ `week_01`, `week_02`, ...
