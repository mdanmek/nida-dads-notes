## 2. ข้อตกลงข้อมูลที่ใช้ร่วมกัน

### 2.1 หน่วยวิเคราะห์

หนึ่งรายการไม่ซ้ำกำหนดด้วยสามคอลัมน์ร่วมกัน:

```python
unique_key = [
    'รหัสโครงการ',
    'เลขประจำตัวนิติบุคคล 13 หลัก',
    'เลขที่สัญญา'
]
```

หนึ่งแถวหลังเตรียมข้อมูลจึงแทน **หนึ่งรายการโครงการ–ผู้รับจ้าง–สัญญา**

`รหัสโครงการ` เป็นส่วนหนึ่งของคีย์ แต่ไม่ใช่ grain ที่ใช้ลดข้อมูลให้เหลือหนึ่งแถวต่อโครงการ

ห้ามสร้างข้อมูลด้วย:

```python
drop_duplicates(subset='รหัสโครงการ')
```

และห้ามรวมหลายสัญญาให้เหลือหนึ่งแถวต่อโครงการเพื่อใช้เป็นฐานของ EDA

### 2.2 ลำดับการเตรียมข้อมูล

1. เลือกเฉพาะประเภทโครงการ `จ้างก่อสร้าง`
2. ตัดรหัสผู้รับจ้างที่ขึ้นต้นด้วย `D`
3. ตัดแถวซ้ำด้วย `unique_key`
4. เก็บหลายสัญญาภายในรหัสโครงการเดียวกัน
5. เก็บผู้รับจ้างหลายรายภายในรหัสโครงการเดียวกัน

### 2.3 คอลัมน์มูลค่า

ใช้คอลัมน์นี้เป็นมูลค่าตลอด Notebook 02–04:

```python
contract_value_column = 'วงเงินงบประมาณในสัญญา (บาท)'
```

ไม่ใช้คอลัมน์ต่อไปนี้ในการแบ่งช่วงมูลค่า รวมมูลค่า หรือคำนวณสัดส่วนมูลค่า:

- `วงเงินงบประมาณ (บาท)`
- `ราคาที่ตกลงซื้อ / จ้าง ซึ่งรวมทุกสัญญาในโครงการ (บาท)`

คอลัมน์ดังกล่าวเก็บไว้เป็นข้อมูลประกอบได้ แต่ไม่ใช้แทนมูลค่าสัญญา

### 2.4 คอลัมน์ตามวัตถุประสงค์

| วัตถุประสงค์ | คอลัมน์ |
|---|---|
| ระบุโครงการ | `รหัสโครงการ` |
| ระบุผู้รับจ้าง | `เลขประจำตัวนิติบุคคล 13 หลัก` |
| ระบุสัญญา | `เลขที่สัญญา` |
| มูลค่า | `วงเงินงบประมาณในสัญญา (บาท)` |
| วิธีจัดซื้อ | `ชื่อวิธีการจัดซื้อจัดจ้าง` |
| จังหวัด | `จังหวัด` |
| หน่วยงาน | `ชื่อหน่วยงาน` |
| หน่วยงานย่อย | `ชื่อหน่วยงานย่อย` |

### 2.5 ลำดับชั้นหน่วยงาน

`ชื่อหน่วยงานย่อย` เป็น subset ของ `ชื่อหน่วยงาน` การวิเคราะห์ระดับหน่วยงานย่อยจึงต้องใช้สองคอลัมน์ร่วมกัน:

```python
[
    'ชื่อหน่วยงาน',
    'ชื่อหน่วยงานย่อย'
]
```

ห้ามจัดกลุ่มด้วย `ชื่อหน่วยงานย่อย` เพียงคอลัมน์เดียว

## 6. Notebook 04 — Review Indicators

ไฟล์: `04_construction_review_indicators_2569.ipynb`

### 6.1 อ่านและ preview ข้อมูล

อ่านไฟล์เดียว:

```text
construction_contract_supplier_study_scope_2569.csv
```

หลังอ่านให้แสดง:

```python
print(f'Shape: {study_scope_data.shape}')
display(study_scope_data.head())
```

ไม่ตรวจ JV ไม่ตัด duplicate และไม่ทำ reconciliation ซ้ำ

### 6.2 การนับจำนวน

จำนวนรายการสัญญาใช้จำนวนแถวจาก unique key

หากต้องแสดงจำนวนโครงการเป็นข้อมูลประกอบ ให้ใช้ `รหัสโครงการ.nunique()` และระบุชัดว่าเป็นข้อมูลประกอบ ไม่ใช้แทนจำนวนรายการสัญญาใน Pattern

### 6.3 Pattern 1 — สัญญาใกล้เพดานที่เกิดซ้ำ

เงื่อนไข:

- วิธีเฉพาะเจาะจง
- `วงเงินงบประมาณในสัญญา (บาท)` อยู่ในช่วง 490,000–500,000 บาท
- คู่ `ชื่อหน่วยงาน + ชื่อหน่วยงานย่อย + ผู้รับจ้าง` เดียวกัน
- อย่างน้อย 3 รายการ unique key
- ไม่ใช้วันที่เกิดรายการ

คอลัมน์จัดกลุ่ม:

```python
[
    'ชื่อหน่วยงาน',
    'ชื่อหน่วยงานย่อย',
    'เลขประจำตัวนิติบุคคล 13 หลัก'
]
```

### 6.4 Pattern 2 — การพึ่งพาผู้รับจ้างในชื่อหน่วยงาน

จัดกลุ่มด้วย:

```python
[
    'ชื่อหน่วยงาน',
    'เลขประจำตัวนิติบุคคล 13 หลัก'
]
```

เกณฑ์:

- ผู้รับจ้างได้รับอย่างน้อย 10 รายการสัญญา
- สัดส่วนจำนวนรายการสัญญาอย่างน้อย 75%
- สัดส่วนวงเงินสัญญาอย่างน้อย 75%

ทั้งตัวตั้งและตัวหารของสัดส่วนวงเงินใช้ `วงเงินงบประมาณในสัญญา (บาท)`

### 6.5 Pattern 3 — การพึ่งพาผู้รับจ้างในชื่อหน่วยงานย่อย

จัดกลุ่มด้วย:

```python
[
    'ชื่อหน่วยงาน',
    'ชื่อหน่วยงานย่อย',
    'เลขประจำตัวนิติบุคคล 13 หลัก'
]
```

ตัวหารคำนวณภายใน:

```python
[
    'ชื่อหน่วยงาน',
    'ชื่อหน่วยงานย่อย'
]
```

ใช้เกณฑ์เดียวกับ Pattern 2

### 6.6 Pattern 4 — การพึ่งพาผู้รับจ้างในจังหวัด

จัดกลุ่มด้วย:

```python
[
    'จังหวัด',
    'เลขประจำตัวนิติบุคคล 13 หลัก'
]
```

เกณฑ์:

- จังหวัดมีอย่างน้อย 20 รายการสัญญา
- ผู้รับจ้างได้รับอย่างน้อย 5 รายการสัญญา
- สัดส่วนจำนวนรายการสัญญาอย่างน้อย 50%
- สัดส่วนวงเงินสัญญาอย่างน้อย 50%

### 6.7 การจัดลำดับตรวจสอบ

ใช้:

```text
Pattern 1 และ (Pattern 2 หรือ Pattern 3)
```

Pattern 4 เป็นบริบทระดับจังหวัด ไม่รวมใน priority

ผลสุดท้ายให้นับ unique key ไม่ใช่นับเฉพาะรหัสโครงการ

## 8. Markdown และ Code style

### Markdown

- ไม่บรรยายผลก่อนรัน cell
- Markdown ก่อน code บอกเฉพาะคำถามหรือสิ่งที่จะคำนวณ
- Markdown หลัง output อธิบายเฉพาะสิ่งที่เห็น
- ไม่กล่าวล่วงหน้าว่าจะพบ Pattern หรือได้จำนวนเท่าใด
- ไม่ใส่ตัวเลข output เป็นข้อความคงที่หากผลยังเปลี่ยนได้
- ไม่เรียกรายการว่า fraud หรือทุจริต
- อธิบายว่าหนึ่งแถวของทุกตารางแทน grain ใด
- แก้ README หลังยืนยัน output ใหม่แล้วเท่านั้น

### Code

- ใช้ single quotes
- ใช้ pandas, NumPy, Matplotlib และ Seaborn ระดับพื้นฐาน
- ไม่สร้าง class
- ไม่ใช้ abstraction ซับซ้อน
- ใช้ function เฉพาะส่วนที่คำนวณซ้ำจริง
