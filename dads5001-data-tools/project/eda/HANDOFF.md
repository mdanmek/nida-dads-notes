## สถานะที่ยืนยันแล้ว

### ข้อมูลและ grain

- ข้อมูลต้นทาง: 3,964,924 ระเบียน
- สัญญาจ้างก่อสร้างก่อนตัดรหัสผู้รับจ้าง `D`: 180,079 สัญญา
- ตัดออก: 363 สัญญา
- ข้อมูลวิเคราะห์: 179,716 สัญญา
- Grain: `รหัสโครงการ + รหัสผู้รับจ้าง + เลขที่สัญญา`
- Pair grain: ชื่อหน่วยงาน + ผู้รับจ้าง
- ไม่ใช้หน่วยงานย่อยเป็น grain
- จังหวัดเป็นบริบท/ตัวเรียงลำดับ แต่ไม่เข้า criteria

### Scope และ Pattern

- Study Scope: งานก่อสร้าง + วิธีเฉพาะเจาะจง + วงเงินไม่เกิน 500,000 บาท
- Study Scope = 136,122 สัญญา
- Pattern 1: คู่เดิมมีสัญญา 490,000–500,000 บาทอย่างน้อย 3 สัญญา
- Pattern 1 = 9,413 สัญญา / 1,580 คู่
- Pattern 2: คู่เดิมมีอย่างน้อย 10 สัญญา และครองทั้งจำนวนกับมูลค่าในหน่วยงานตั้งแต่ 80%
- Pattern 2 = 1,343 สัญญา / 79 คู่
- Priority Review = จุดตัด Pattern 1 และ Pattern 2 = 161 สัญญา

เกณฑ์ 3, 10 และ 80% เป็น analyst-defined screening thresholds ไม่ใช่ข้อกฎหมาย
