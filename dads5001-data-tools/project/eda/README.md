# จากข้อมูลจัดซื้อจัดจ้าง สู่รายการตรวจสอบลำดับแรก

> การวิเคราะห์ข้อมูลจัดซื้อจัดจ้างงานก่อสร้าง ปีงบประมาณ 2569  
> เป้าหมายคือใช้ข้อมูลจัดลำดับการตรวจเอกสาร ไม่ใช่ตัดสินว่ารายการใดทุจริต

## คำถามที่เราอยากตอบ

จากข้อมูลจัดซื้อจัดจ้างทั้งหมด เราพบสัญญาณอะไรในงานก่อสร้าง เหตุใดจึงเลือกศึกษารายการเฉพาะเจาะจงใกล้ 500,000 บาท และจะลดรายการจำนวนมากให้เหลือกลุ่มที่ควรเปิดเอกสารตรวจสอบก่อนได้อย่างไร

## เรื่องย่อ

เราเริ่มจากข้อมูล e-GP ปีงบประมาณ 2569 จำนวน **3,964,924 รายการ** เลือกเฉพาะประเภทโครงการ **จ้างก่อสร้าง 180,079 รายการ** และตัดรหัสผู้รับจ้างที่ขึ้นต้นด้วย `D` จำนวน 363 รายการ เหลือข้อมูลระดับสัญญา–ผู้รับจ้าง **179,716 รายการ**

เมื่อสำรวจข้อมูลก่อสร้าง พบว่าช่วงวงเงิน 400,000–500,000 บาทมีสัดส่วนสูง และเมื่อขยายดูรอบ 500,000 บาท พบการกระจุกในช่วง 490,000–500,000 บาท อีกทั้งรายการใกล้เพดาน 98.78% ใช้วิธีเฉพาะเจาะจง ข้อค้นพบนี้จึงนำไปสู่การกำหนดขอบเขตศึกษา Pattern เป็น **วิธีเฉพาะเจาะจงและวงเงินไม่เกิน 500,000 บาท**

หลังตรวจ Pattern ซ้ำของคู่หน่วยงาน–ผู้รับจ้างและการกระจุกตัวของผู้รับจ้างร่วมกัน เหลือ **161 รายการ** สำหรับตรวจเอกสารเป็นลำดับแรก

## 1. เรามีข้อมูลอะไร

| ขั้นตอน | จำนวน | หน่วย/ความหมาย |
|---|---:|---|
| ข้อมูล e-GP ปีงบประมาณ 2569 | 3,964,924 | รายการจัดซื้อจัดจ้างทั้งหมด |
| เลือกประเภท “จ้างก่อสร้าง” | 180,079 | รายการก่อนทำความสะอาด |
| ตัดรหัสผู้รับจ้างขึ้นต้นด้วย `D` | −363 | รายการที่ไม่นำมาวิเคราะห์ |
| ข้อมูลที่ใช้วิเคราะห์ | **179,716** | รายการสัญญา–ผู้รับจ้าง |

หนึ่งแถวของข้อมูลวิเคราะห์กำหนดด้วย:

```text
รหัสโครงการ
+ เลขประจำตัวนิติบุคคล 13 หลัก
+ เลขที่สัญญา
```

ดังนั้น จำนวนรายการสัญญา–ผู้รับจ้างอาจมากกว่าจำนวนรหัสโครงการไม่ซ้ำ เพราะหนึ่งโครงการสามารถมีมากกว่าหนึ่งสัญญาหรือผู้รับจ้างได้

## 2. เราพบอะไรในข้อมูลก่อสร้าง

การสำรวจภาพรวมพบว่า ช่วงวงเงิน 400,000–500,000 บาทมีสัดส่วนรายการสูงที่สุดที่ 25.09% และวิธีเฉพาะเจาะจงเป็นวิธีหลักของงานก่อสร้าง คิดเป็น 76.35% ของรายการทั้งหมด สิ่งนี้ทำให้บริเวณ 500,000 บาทเป็นจุดที่ควรขยายดูรายละเอียด

## 3. จุดที่สะดุดตา: การกระจุกบริเวณ 500,000 บาท

เมื่อขยายช่วง 400,000–550,000 บาท พบการกระจุกของรายการบริเวณ 490,000–500,000 บาท

![การกระจายวงเงินบริเวณ 500,000 บาท](figure/fig05_02_contract_distribution_around_500k.png)

การกระจุกตัวเป็นสัญญาณสำหรับตั้งคำถามต่อ แต่ยังไม่ใช่หลักฐานความผิดปกติด้วยตัวมันเอง

## 4. รายการใกล้เพดานสัมพันธ์กับวิธีใด

เมื่อดูรายการช่วง 490,000–500,000 บาททั้งหมด 20,450 รายการ พบว่า:

| วิธีจัดซื้อจัดจ้าง | จำนวน | สัดส่วน |
|---|---:|---:|
| เฉพาะเจาะจง | 20,200 | 98.78% |
| e-bidding | 238 | 1.16% |
| คัดเลือก | 12 | 0.06% |

![วิธีจัดซื้อจัดจ้างของรายการใกล้เพดาน](figure/fig05_03_method_near_500k.png)

ข้อค้นพบนี้เป็นเหตุผลที่เราเลือกศึกษาวิธีเฉพาะเจาะจงต่อ ไม่ได้กำหนด scope นี้ไว้ก่อนเห็นข้อมูล

## 5. จึงกำหนดขอบเขตสำหรับศึกษา Pattern

ขอบเขตศึกษา Pattern คือ:

- ประเภทโครงการ: จ้างก่อสร้าง
- วิธีจัดซื้อจัดจ้าง: เฉพาะเจาะจง
- วงเงินในสัญญา: ไม่เกิน 500,000 บาท
- ช่วงใกล้เพดาน: 490,000–500,000 บาท

จากข้อมูลวิเคราะห์ 179,716 รายการ เหลือรายการในขอบเขตศึกษา 136,122 รายการ และมีรายการใกล้เพดานภายในขอบเขต 20,200 รายการ

![ขอบเขตข้อมูลสำหรับศึกษา Pattern](figure/fig05_01_study_scope.png)

## 6. จากรายการเดี่ยว สู่คู่หน่วยงาน–ผู้รับจ้าง

เราเปลี่ยน grain จากรายการสัญญาเป็นคู่ **ชื่อหน่วยงาน + ผู้รับจ้าง** เพื่อดูว่าคู่เดิมมีรายการใกล้เพดานเกิดซ้ำหรือไม่ Pattern 1 พบ 9,413 รายการ กระจายอยู่ใน 1,580 คู่หน่วยงาน–ผู้รับจ้าง

![คู่หน่วยงานและผู้รับจ้างที่เกิดซ้ำ](figure/fig05_04_top_repeated_near_ceiling_pairs.png)

Pattern 1 ครอบคลุม 46.60% ของรายการใกล้เพดาน จึงเป็นสัญญาณที่กว้างเกินกว่าจะใช้ตัดสินลำพัง

## 7. ใช้สองสัญญาณร่วมกันเพื่อลดการหว่านแห

Pattern 2 มองผู้รับจ้างที่มีอย่างน้อย 10 รายการ และครองอย่างน้อย 80% ของทั้งจำนวนรายการและมูลค่างานภายในหน่วยงาน เมื่อซ้อนกับ Pattern 1 เหลือ **161 รายการ**

![เส้นทางการคัดกรองรายการตรวจสอบ](figure/fig05_05_review_filtering_journey.png)

จุดตัดนี้มีทั้งความถี่ใกล้เพดานในคู่เดิมและการกระจุกตัวของผู้รับจ้างในหน่วยงานเดียวกัน จึงเหมาะสำหรับจัดเป็นลำดับตรวจเอกสารก่อน

## 8. ผลลัพธ์คือคิวตรวจสอบที่ลงมือทำได้

![คู่หน่วยงานและผู้รับจ้างสำหรับตรวจสอบก่อน](figure/fig05_06_top_priority_pairs.png)

ควรตรวจเอกสารประกอบ เช่น TOR ราคากลาง วันที่ประกาศและทำสัญญา ความเชื่อมโยงของโครงการ การแข่งขันเสนอราคา และประวัติผู้รับจ้าง ก่อนสรุปผลใด ๆ

## นิยามเกณฑ์

| Flag | เกณฑ์ | บทบาท |
|---|---|---|
| Pattern 1 | คู่ชื่อหน่วยงาน + ผู้รับจ้างเดียวกัน มีรายการ 490,000–500,000 บาทอย่างน้อย 3 รายการ | ค้นหารูปแบบซ้ำใกล้เพดาน |
| Pattern 2 | ผู้รับจ้างมีอย่างน้อย 10 รายการ และครอง ≥80% ทั้งสัดส่วนจำนวนและมูลค่าในหน่วยงาน | ค้นหาการกระจุกตัวสูง |
| Priority Review | Pattern 1 และ Pattern 2 เป็นจริงพร้อมกัน | จัดลำดับตรวจเอกสาร |
| จังหวัด | แสดงและจัดเรียงผลลัพธ์เช่นเดียวกับ grain อื่น | ใช้เป็นบริบท ไม่เข้า criteria |
| หน่วยงานย่อย | ไม่นำมาใช้ | ตัด mapping และ grain นี้ออก |

ตัวเลข 3, 10 และ 80% เป็น **analyst-defined screening thresholds** ไม่ใช่เกณฑ์ทางกฎหมาย และควรทำ sensitivity analysis หากนำไปใช้ตัดสินใจจริง

## ข้อจำกัด

- Flag เป็นเครื่องมือคัดกรอง ไม่ใช่ข้อพิสูจน์การทุจริตหรือการหลีกเลี่ยงกฎ
- ชื่อหน่วยงานและผู้รับจ้างอาจคลาดเคลื่อนจากการสะกดหรือรูปแบบการบันทึก
- การวิเคราะห์ยังไม่รวมเนื้อหา TOR ราคากลาง คุณสมบัติผู้เสนอราคา และความสัมพันธ์เชิงนิติบุคคล
- จังหวัดใช้เพื่ออธิบายบริบทและไม่มีผลต่อ criteria
- ผลลัพธ์ขึ้นกับช่วงวงเงินและ threshold ที่กำหนด
