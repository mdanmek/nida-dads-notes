# แผนการปรับปรุง Notebook รอบที่ 1

## เป้าหมายของรอบนี้

ปรับ Notebook ของการวิเคราะห์โครงการจ้างก่อสร้างปีงบประมาณ 2569
ให้มีเนื้อหาต่อเนื่อง ตัวเลขสอดคล้องกัน และสามารถรันจากต้นจนจบได้
โดยไม่มี Error

รอบนี้เน้นแก้ความถูกต้องของข้อมูล โค้ด และข้อสรุปก่อน
ยังไม่เน้นการจัดรูปแบบสำหรับ README หรือ Presentation

## Definition of Done สำหรับรอบที่ 1

Notebook ของเป้ถือว่าผ่านการปรับปรุงรอบแรกเมื่อ:

1. Notebook 02-04 รันตามลำดับใน Colab runtime ใหม่ได้โดยไม่มี Error
2. ตัวเลขสำคัญตรงกับรายการอ้างอิงในเอกสารนี้
3. ไม่มีข้อสรุป Supplier แบบเก่าหลงเหลือใน Notebook 03
4. Markdown ใน Notebook 04 เป็นภาษาไทย
5. Data-quality issue และ Procurement-review indicator ถูกแยกออกจากกัน
6. ไม่มีการนับตัวชี้วัดราคาเป็นสองมิติซ้ำกัน
7. Input และ Output ของแต่ละ Notebook เชื่อมต่อกันถูกต้อง
8. กรณีศึกษาสามารถย้อนกลับไปตรวจสอบ Contract-level rows ได้
